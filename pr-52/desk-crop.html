How this experiment works

The page crops the actual camera pixels before sending them to the bundled hand model. Both inputs use the same moment, keep their aspect ratio, and fit within 640 × 640 pixels without upscaling. Separate model instances keep their tracking histories independent. Two models make this a framing comparison, not a production speed benchmark.

Software cropping cannot recover detail absent from the source. Apple’s native Desk View controls may change framing earlier in the camera pipeline; a website cannot open that native setup API. The zoom control above appears only if this camera exposes zoom to the browser.

If Desk View is missing, use Safari and enable Desk View in macOS first, then start the camera again. If you adjust Apple’s framing while this page is open, select a new crop. Nothing is saved, recorded or uploaded, and your practice calibration is untouched.
